כתר מלכות · c. 1050

לט

by Solomon ibn Gabirol c. 1021–c. 1058

יְהִי רָצוֹן מִלְּפָנֶיךָ, יְיָ אֱלֹהַי, לָשׁוּב עָלַי בְּרַחֲמֶיךָ / וּלַהֲשִׁיבֵנִי בִּתְשׁוּבָה שְׁלֵמָה לְפָנֶיךָ / וּלִתְחִנָּתִי תָּכִין לִבִּי, תַּקְשִׁיב אָזְנֶךָ / וְתִפְתַּח לִבִּי בְתוֹרָתֶךָ / וְתִטַּע בְּרַעְיוֹנַי יִרְאָתֶךָ / וְתִגְזֹר עָלַי גְּזֵרוֹת טוֹבוֹת / וּתְבַטֵּל מֵעָלַי גְּזֵרוֹת רעוֹת / וְאַל תְּבִיאֵנִי לִידֵי נִסָּיוֹן / וְלֹא לִידֵי בִזָּיוֹן / וּמִכָּל פְּגָעִים רָעִים הַצִּילֵנִי / וְעַד יַעֲבֹר הַוּוֹת בְּצִלְךָ תַּסְתִּירֵנִי / וֶהְיֵה עִם פִּי וְהֶגְיוֹנִי / וּשְׁמֹר דְּרָכַי מֵחֲטוֹא בִלְשׁוֹנִי / וְזָכְרֵנִי בְּזִכְרוֹן עַמֶּךָ / וּבְבִנְיַן אוּלַמֶּךָ / לִרְאוֹת בְּטוֹבַת בְחִירֶיךָ / וְזַכֵּנִי לְשַׁחֵר דְּבִירֶךָ הַשָּׁמֵם וְהֶחָרֵב, וְלִרְצוֹת אֲבָנָיו וְעַפְרוֹתָיו / וְרִגְבֵי חָרְבוֹתָיו / וְתִבְנֶה שׁוֹמְמוֹתָיו.
