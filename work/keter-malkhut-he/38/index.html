כתר מלכות · c. 1050

לח

by Solomon ibn Gabirol c. 1021–c. 1058

אֱלֹהַי, אִם עֲוֹנִי מִנְּשׂוֹא גָּדוֹל / מַה תַּעֲשֶׂה לְשִׁמְךָ הַגָּדוֹל / וְאִם לֹא אוֹחִיל לְרַחֲמֶיךָ / מִי יָחוּס עָלַי חוּץ מִמֶּךָּ / לָכֶן אִם תִּקְטְלֵנִי לְךָ אֲיַחֵל / וְאִם תְּבַקֵּשׁ לַעֲוֹנִי, אֶברַח מִמֶּךָּ אֵלֶיךָ / וְאֶתְכַּסֶּה מֵחֲמָתְךָ בְּצִלֶּךָ / וּבְשׁוּלֵי רַחֲמֶיךָ אַחֲזִיק עַד אִם רִחַמְתַּנִי / וְלֹא אֲשַׁלַּחֲךָ כִּי אִם בֵּרַכְתָּנִי / זְכָר נָא כִּי כַחֹמֶר עֲשִׂיתַנִי / וּבְאֵלֶּה הַתְּלָאוֹת נִסִּיתָנִי / עַל כֵּן לֹא תִפְקֹד עָלַי כְּמַעֲלָלַי / וְאַל תַאֲכִילֵנִי פְּרִי פְעָלַי / וְהַאֲרֶךְ לִי אַפְּךָ וְאַל תַּקְרִיב יוֹמִי / עַד אָכִין צֵדָה לָשׁוּב אֶל מְקוֹמִי / וְאַל תֶּחֱזַק עָלַי לְמַהֵר לְשַׁלְּחֵנִי מִן הָאָרֶץ, וּמִשְׁאֲרוֹת אֲשָׁמִי / צְרוּרוֹת עַל שִׁכְמִי / וּבְהַעֲלוֹתְךָ בְּמִשְׁקָל עֲוֹנוֹתַי / שִׂים לְךָ בְּכַף שְׁנִיָּה תְּלָאוֹתַי / וּבְזָכְרְךָ רִשְׁעִי וּמִרְדִּי / זְכֹר עָנְיִי וּמְרוּדִי / וְשִׂים אֵלֶּה / נֹכַח אֵלֶּה / וּזְכָר נָא, אֱלֹהַי, כִּי זֶה כַּמֶּה לְאֶרֶץ נוֹד צְנַפְתַּנִי / וּבְכוּר גָּלוֹת בְחַנְתָּנִי / וּמֵרֹב רִשְׁעִי צְרַפְתָנִי / וְיָדַעתִי כִּי לְטוֹבָתִי נִסִּיתַנִי / וֶאֱמוּנָה עִנִּיתַנִי / וּלְהַטִיב לִי בְאַחְרִיתִי בְּמִבְחַן הַתְּלָאוֹת הֲבֵאתָנִי / לָכֵן, אֱלֹהַי, יֶהֱמוּ עָלַי רַחֲמֶיךָ / וְאַל תְּכַלֶּה עָלַי זַעְמֶךָ / וְאַל תִּגְמְלֵנִי כְמַעְבָּדַי / וֶאֱמֹר לַמַּלְאָךְ הַמַּשְׁחִית דַּי / וּמַה מַּעֲלָתִי וְיִתְרוֹנִי / כִּי תְבַקֵּשׁ לַעֲוֹנִי / וְתָשִׂים עָלַי מִשְׁמָר / וּתְצוּדֵנִי כְּתוֹא מִכְמָר / הֲלֹא יָמַי, חָלַף רֻבָּם וְאֵינָם / וְהַנִשְׁאָרִים יִמַּקּוּ בַעֲוֹנָם / וְאִם הַיּוֹם לְפָנֶיךָ הִנֵּנִי / מָחָר עֵינֶיךָ בִּי, וְאֵינֶנִּי / וְעַתַּה לָמָּה אָמוּת / כִּי תֹאכְלֵנִי הָאֵשׁ הַגְּדוֹלָה הַזֹּאת / אֱלֹהַי, שִׂים עֵינֶיךָ עָלַי לְטוֹבָה לִשְׁאֵרִית יָמַי הַמְּעַטִּים / וְאַל תִּרְדֹּף הַשְּׂרִידִים וְהַפְּלֵטִים / וְהַפְּלֵטָה הַנִּשְׁאֶרֶת מִבְּרַד מְהוּמוֹתַי / אַל יְחַסְלֶנָּה יֶלֶק אַשְׁמוֹתַי / כִּי יְצִיר כַּפֶּיךָ אָנִי / וּמַה יִּסְכָּן לָךְ כִּי רִמָּה תִּקָּחֵנִי לְאֹכֶל / יְגִיעַ כַּפֶּיךָ כִּי תֹאכֵל.
